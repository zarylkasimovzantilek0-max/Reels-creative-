# Референс талдауы — әр 0,5 секунд

Референс: https://www.instagram.com/reel/DfwNBVvN-WQ/ (20,6 с, 1080×1920, 30 fps)

Видеода екі панель бар: сол жақта «Дейін» (өңделмеген видео), оң жақта «Кейін» (дайын монтаж). Төмендегі
талдау «Кейін» панеліне жасалған: кадрлар әр 0,5 с сайын, ал ауысулар маңында әр 0,1 с сайын алынды. Дыбыс
спектрограммамен және жоғары жиіліктегі онсеттер (соққылар) бойынша тексерілді. Жақшадағы сандар —
дыбыс соққысы табылған нақты секунд.

## Жалпы стиль

| Элемент | Референсте қалай |
|---|---|
| Музыка | Бірінші кадрдан бастап үздіксіз жүреді, интросы жоқ. Басы басым, дауыстан шамамен 15–20 дБ төмен. Соңына дейін тоқтамайды. |
| Дауыс | Алдыңғы планда, анық, компрессияланған. |
| Ырғақ | Әр 0,5–1,0 с сайын бір оқиға болады: мәтін, кесу, зум, UI элемент немесе жарқыл. |
| Зум | Үлкен мәтін шыққанда кенет зум-ин (≈1,1–1,2x), мәтін кеткенде зум-аут. Бөлім ауысқанда кадр кішірейіп «карточка» болады да, артынан ашық сұр фон шығады. |
| Ауысулар | Hard cut, жарық жарқылы (light leak), blur-ауысу, төменге/жоғарыға сырғу. |
| SFX | Әр мәтінде pop/click, әр ауысуда whoosh, маңызды сөзде impact, прогресс жүргенде riser, соңында ding, жазу кезінде typing. |
