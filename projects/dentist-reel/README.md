# Тіс дәрігері: Reels монтажы

- **Бастапқы видео:** WhatsApp видеосы, 478×850, 59,94 fps, 19,7 с. Бір кадрмен түсірілген, сөйлеп тұрған адам.
- **Нәтиже:** `output/dentist_reel_final.mp4`, 1080×1920, 30 fps, H.264 + AAC 256k, −13,8 LUFS, peak −1 dBFS.
- **Референс:** https://www.instagram.com/reel/DfwNBVvN-WQ/ (талдауы: `sound-design/reference_analysis.md`)

## Монтаж қалай жасалды

1. **Сөйлеу фразалары** дауыс энергиясы бойынша табылды. Зум мен SFX сөздің ортасына емес, фраза басталатын
   жерге немесе сөз арасындағы үзіліске қойылды. Фразалар: 0.49–1.99, 2.53–5.04, 5.59–6.76, 7.18–8.42,
   8.63–11.41, 12.03–13.72, 14.26–16.30, 16.70–17.93, 18.22–18.72.
2. **Бет** Haar каскадымен табылды. Траектория 1,2 с бойы тегістелді, сондықтан камера «қуып жүрген» сияқты
   көрінбейді, тұрақты тұрады. Зум-ин кезінде бет экран биіктігінің 40%-ында тұрады.
3. Референстің ырғағы көшірілді: әр 1–1,5 с сайын бір оқиға болады (зум, ауысу немесе SFX).

## Түс және сапа

- Контраст +6%, қанықтық +12%.
- 478×850-ден 1080×1920-ға бір қадаммен Lanczos масштабтау жасалды, үстінен жеңіл sharpen берілді.
- Жылдам зумдарда кадр ішінде 2–9 субкадр жинақталып, motion blur шығады (180° shutter).
